# hanko-login-sample

デジタル署名に基づく分散型認証方式である[Hanko](https://github.com/code4fukui/hanko/)を使用した、クライアントサイドのログインフローを示すサンプルWebアプリケーションです。

## デモ

ライブデモは以下から利用可能です: **[https://code4fukui.github.io/hanko-login-sample/](https://code4fukui.github.io/hanko-login-sample/)**

## 動作の流れ

このサンプルは、クライアントサイドで完結する認証ループを示しています:

1.  ユーザーがこのサンプルアプリ（「何かのサービス」）のログインボタンをクリックします。
2.  アプリが新しいタブでHanko Webアプリを開き、署名対象のメッセージを渡します。
3.  ユーザーがHankoアプリ内で認証を行い、メッセージに署名します。
4.  Hankoがユーザーをこのサンプルアプリにリダイレクトし、URLパラメータとして署名を渡します。
5.  サンプルアプリのJavaScriptが、署名、その内容、およびタイムスタンプを検証します。
6.  検証に成功すると、`localStorage`にセッションが作成され、ユーザーの公開鍵が表示されます。

## 特徴

-   **分散型ログイン:** Hankoのデジタル署名フローを通じてユーザーを認証します。
-   **セッションの永続化:** ブラウザの`localStorage`にユーザーセッションを保存します。
-   **ユーザー識別:** ログイン成功後、ユーザーの公開鍵（DID）を表示します。
-   **ログアウト:** `localStorage`からセッションを削除します。

## 必要条件

-   ES6モジュールをサポートするモダンWebブラウザ。

## 使い方

1.  Webブラウザで`index.html`ファイルを開くか、デモURLにアクセスします。
2.  **「Hankoでログイン」** ボタンをクリックします。
3.  新しいタブで開いたHankoアプリを使用し、ログインリクエストに署名します。
4.  署名後、サンプルアプリケーションにリダイレクトされて戻ります。
5.  ログインに成功すると、公開鍵を含むウェルカムメッセージが表示されます。
6.  ログアウトするには、**「ログアウト（セッション削除）」** ボタンをクリックします。

## 依存関係

このプロジェクトは以下の外部ライブラリに依存しています:
-   [Hanko](https://github.com/code4fukui/hanko/) - 分散型認証に使用。
-   [QRCode.js](https://js.sabae.cc/QRCode.js) - QRコードの生成に使用。
-   [DateTime.js](https://js.sabae.cc/DateTime.js) - 日時操作の処理に使用。
-   [Base32.js](https://code4fukui.github.io/Base32/Base32.js) - セッションIDのエンコードに使用。
